# 🎤 Voice Based Concept Understanding Analyser

An AI-powered web application that evaluates conceptual understanding through spoken explanations.

## Features

- 🎤 Audio Upload
- 📝 Whisper Speech-to-Text
- 📊 Audio Feature Extraction
- 💬 Filler Word Detection
- 🧠 Semantic Similarity (Sentence-BERT)
- 🏆 AI Scoring Engine
- 📈 Interactive Dashboard
- 📄 PDF Report Generation

## Technologies

- Python
- Streamlit
- OpenAI Whisper
- Sentence-BERT
- Librosa
- Plotly
- ReportLab
- PyTorch
